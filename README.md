# Developer Portfolio — Muhammad Agriyansyah

A clean, dark-themed personal developer portfolio built with pure HTML5, CSS3, and Vanilla JavaScript. Features interactive project modals, responsive grid layouts, and custom terminal aesthetic styling to showcase software engineering, web development, and AI projects.

![Portfolio Preview](https://img.shields.io/badge/Status-Live-brightgreen) ![License](https://img.shields.io/badge/License-MIT-blue)

---

## ⚡ Key Features

* **Interactive Case Study Modal:** Built-in modal popup to highlight system pipeline, benchmarks, and high-res screenshots for featured projects without leaving the page.
* **Custom Terminal & Dark Theme:** Styled using custom CSS variables, glassmorphism navbar, and terminal-inspired UI components.
* **Zero Heavy Frameworks:** Ultra-lightweight performance using vanilla HTML, CSS flexbox/grid, and native JavaScript.
* **Fully Responsive:** Optimized layouts for mobile, tablet, and desktop viewports.

---

## 🛠️ Featured Projects Showcase

* **Real-Time Stress Recognition AI (Thesis / Skripsi):** Webcam-based facial expression analysis system using MediaPipe, CNN emotion classification, and fuzzy logic temporal smoothing powered by FastAPI.
* **Enterprise Plant MIS:** Enterprise operational management system engineered during internship using Java, JSP/Servlets, JDBC, and MySQL.
* **Atmosphere Weather Dashboard:** Asynchronous REST API-driven application displaying live weather data and atmospheric metrics.
* **Browser Supply UI Clone:** Modern responsive web interface clone built to demonstrate pixel-perfect layout replication and clean CSS architecture.
